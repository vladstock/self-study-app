
# ITIL Practice Exam - Web App

This project is a lightweight web application for practicing ITIL definitions based on a provided glossary.

Features:
- Uses all glossary definitions from the provided `glossary.txt`.
- For each definition there are 9 options (1 correct + 8 distractors chosen by similarity).
- Exam contains **40 random questions**, exam time **60 minutes**.
- Scoring: 1 point per correct answer. Passing threshold: **26/40**.
- Final review shows your selected answer and the correct answer for each question.

How to run:
1. Extract the project and upload to GitHub repository.
2. Enable GitHub Pages (select `main` branch, `/` root).
3. Open `index.html` via GitHub Pages link.

Files:
- `questions.json` - full dataset (303 entries).
- `index.html`, `script.js`, `styles.css` - web app.
